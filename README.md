# Versal Axis Admin Dashboard

Standard React + Vite + TypeScript administration dashboard for Versal Axis.

## Development

```sh
npm install
npm run dev
```

## Production Build

```sh
npm run build
```

The production output is generated in the `dist/` directory and can be deployed directly to Netlify, Vercel, Render Static Site, GitHub Pages, or any static server.

## Tech Stack

- React 19
- TypeScript
- Vite
- TanStack Router & Query
- Tailwind CSS & Shadcn UI
